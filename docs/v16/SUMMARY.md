## Baseline 桶：LLM 随机性主导波动

Baseline 桶（0.6/0.4，同 V13 权重）的三次独立实验结果：

| 数据集 | V13 | V15 | V16 | 波动范围 |
|--------|-----|-----|-----|---------|
| Steinhart | 0.163 | 0.142 | 0.140 | ±0.023 |
| Replogle_essential | 0.582 | 0.534 | 0.561 | ±0.048 |
| Scharenberg22 | 0.456 | 0.469 | 0.463 | ±0.013 |

**三次实验用同样的权重（0.6/0.4），结果却差异显著。** 根源：LLM（temperature=0.5）每次生成不同的基因列表，单次基因命中数差 1-2 个即造成 `±hit/n_hits` 的精度波动。

对 Steinhart（145 hits）：1 个额外基因 = +0.007 precision（3 seed 均值）。V13 与 V16 之间 -0.023 的差距 ≈ 3-4 个基因的随机差异，在 temperature=0.5 下完全合理。

## 下一步方向

当前权重路由方案已趋于收敛，继续调整权重的边际收益极低。若要突破 avg 0.240，需要改变信号质量本身，而非融合权重：

### 方向一：降低 LLM 随机性
- 将 LLM temperature 从 0.5 降至 0.0-0.1（deterministic 或接近）
- 或 LLM 采样 K 次取并集（ensemble nomination）
- 直接减少 ±0.020 的跨次波动

### 方向二：解决 Replogle_gwps 瓶颈（-0.034 gap）
- V12 在 gwps 的 0.290 来自 ML shortlist 约束 + 跨实验记忆（Replogle_essential 经验）
- V16 用自由 LLM 提名，效果差。gwps（9193 genes, 10.1% hit）是中规模高密度，适合两步策略：
  先用 ML 缩窄到 top-500，再让 LLM 从中选

### 方向三：Carnevale22 单独路由（-0.004 gap）
- Carnevale22 是大基因池数据集中唯一 LLM 优于 ML 的数据集（腺苷通路）
- 可以通过 task description 关键词检测（"Adenosine"）单独归入 LLM 桶
