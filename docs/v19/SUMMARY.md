## 核心发现

### 1. gwps R1 完全一致：两步策略结构性增益确认

```
gwps 各轮命中率：
        R1      R2      R3      R4      R5
V17:   0.064   0.127   0.177   0.217   0.254   (free LLM)
V18:   0.089   0.137   0.181   0.224   0.277   (shortlist=512, 显示80)
V19:   0.089   0.143   0.181   0.234   0.273   (shortlist=384, 全显示)
```

V18 和 V19 的 R1 完全相同（0.089），说明：
- shortlist 大小（384 vs 512）对选择结果几乎无影响
- 截断修复（显示全部 vs 只显示 80）对 LLM 选择几乎无影响
- **gwps 两步策略的真实稳定增益 ≈ +0.019-0.023（vs V17）**

### 2. Scharenberg22：V18 的 0.497 确认为 LLM 方差

```
Scharenberg22 历史（baseline 0.6/0.4，代码完全相同）：
  V17: 0.456
  V18: 0.497  ← 幸运采样
  V19: 0.463  ← 回归正常
```

V19=0.463 处于 V17 的合理范围内，确认 V18 的 0.497 不可复现。

### 3. V18 avg=0.244 的成分分解

| 来源 | 贡献 |
|------|------|
| gwps 两步策略（真实结构性） | +0.023/9 ≈ +0.003 |
| Scharenberg22 幸运采样（不稳定） | +0.041/9 ≈ +0.005 |
| 其他 LLM 方差（中性） | ≈ 0 |
| **V17→V18 净增** | **+0.007** |

去除幸运采样后，稳定 avg ≈ **0.240**（V17=0.237 + gwps 结构增益 +0.003）。

### 4. shortlist 显示方式对 gwps 无显著影响

V18（显示 top-80/512）和 V19（显示全部 384）：
- R1 完全一致（0.089）
- 最终值接近（0.277 vs 0.273，差 0.004 ≈ LLM 方差）

LLM 看到 80 个还是 384 个候选，对 gwps 的选择质量影响可忽略不计。

## gwps 剩余 gap 分析

| 方法 | gwps | 方式 |
|------|------|------|
| V12 WaddingtonArm | 0.290 | ML 384 shortlist → LLM (temp=0.5) |
| V18 WaddingtonV7 | 0.277 | ML 512 shortlist → LLM (temp=0.0) |
| V19 WaddingtonV8 | 0.273 | ML 384 shortlist → LLM (temp=0.0) |
| gap V19 vs V12 | -0.017 | |

剩余 -0.017 gap 的可能原因：
1. **温度差异**：V12 使用 temp=0.5，可能通过探索找到更好的基因组合；temp=0 的贪婪解码在 gwps（高密度 hit 区域）可能次优
2. **提示结构**：V12 的 WaddingtonArm prompt 与 V18/V19 不同，可能更适合 shortlist 场景
3. **随机噪声**：V12 的 0.290 本身在 temp=0.5 下有一定方差，实际稳定值可能 ≈ 0.280

## V20 方向

主要瓶颈已从提示工程转向更底层的问题。两个候选方向：

**方向 A — 更强 LLM（Sonnet 替换 Haiku）**  
当前使用 `claude-haiku-4-5-20251001`，换为 `claude-sonnet-4-6` 可能提升生物推理质量。预期主要改善 baseline 数据集（Steinhart, Scharenberg22, Replogle_essential）。代价：API 费用 3-5 倍增加。

**方向 B — ML 特征增强**  
当前 ML 模型（LOO LightGBM）特征仅包含 PPI 得分等静态特征。加入表达谱特征（GTEx, DepMap）可提升 IFNG/IL2/Sanchez21 等大池数据集的 ML 召回率。代价：数据工程工作量大。
