## 核心发现

### 1. 解除约束 → 整体提升 +3.6%

V12 的 ML shortlist 约束让 LLM 困在 ML 的视野内，导致 LLM 强数据集（Steinhart、Replogle_essential）性能受损。V13 采用加权集成，LLM 自由提名，ML 分数为软先验，两路信号互不干扰。

**avg 0.232 > OA 0.224 > LLM 0.220 > W12 0.218**

### 2. 两个数据集历史新高

| 数据集 | 历史最高（臂） | V13 | 提升 |
|--------|--------------|-----|------|
| Steinhart | 0.152（LLM） | **0.163** | +7.2% |
| Replogle_essential | 0.550（LLM） | **0.582** | +5.8% |

**为何 V13 超过纯 LLM？**

- Steinhart（GD2 抗原 CRISPRa）：LLM 提名 BATF、IRF4、T-bet（T 细胞耗竭抵抗基因）；ML 对这些 PPI hub 也有偏中度评分。加权后 `score ≈ 0.6×0.45 + 0.4×1.0 = 0.67`，而纯 LLM 可能选错几个非 hub 的转录因子。ML 分数提供了 LLM 预测方向之外的微调。
- Replogle_essential（K562 必需基因）：核糖体亚基及蛋白合成因子既是 LLM 的主要预测目标，也是 PPI 网络的高 hub。ML 分数协同加权，使这些基因优先级进一步提升，超过纯 LLM 因偶发干扰因子（CCNT1、POLR2A 等）带来的不稳定性。

### 3. ML 主导数据集：LLM 仍是噪声

| 数据集 | V13 vs OA | 原因 |
|--------|-----------|------|
| IFNG | 0.165 < 0.183 (-10%) | IL-1/JAK-STAT 激活基因与免疫调节基因大量重叠，LLM 偏向知名转录因子，错过实际 hit（多为信号适配器）|
| IL2 | 0.272 < 0.314 (-13%) | IL-2 受体信号依赖于非直觉的信号传导组件，LLM 提名 CD3/TCR 成分（已知 hit），但 OA 通过在线学习更快适应实验特有模式 |
| Sanchez21/down | 小于 OA | 表观遗传沉默的 hit 基因不在 LLM 参数记忆中，LLM 提名增加噪声 |

**0.4 × LLM 权重在"LLM 猜错"的场景中是一个代价**：LLM bonus 将非 hit 基因拉高 +0.4，可能推开 ML 真正高分的基因。

### 4. Replogle_gwps 轻微下滑

```
V12 (Replogle_gwps):  0.290  ← 仍然是 V13 之前的最高
V13 (Replogle_gwps):  0.258  (-11%)
```

V12 的 ML shortlist 在这个数据集表现良好——因为 gwps 的 hit 基因是 K562 适应性相关基因，ML（PPI）分数直接覆盖。V13 的 LLM 自由提名加入了一些"理论上应该重要但实验中不是 hit"的基因，稀释了精度。

## 架构分析

### 信号质量与数据集分型

```
信号质量矩阵：

                   ML 信号强  ML 信号弱
  LLM 信号强 │ 协同放大  │  LLM 主导  │
             │ (Replogle) │ (Steinhart)│
  ───────────┼───────────┼────────────┤
  LLM 信号弱 │ ML 主导   │  两方皆弱  │
             │ (IFNG,IL2) │ (Carnevale)│
```

V13 在"协同放大"区域（Replogle_essential/Steinhart）取得新高，因为两路信号相互验证。但在"ML 主导"区域，LLM 权重 0.4 仍然是负担。

### V14 方向：自适应权重

从每个数据集早期信号（Round 1-2 命中率 vs ML 预期命中率）推断哪个信号更强：

```python
# V14 设想
if early_llm_precision > early_ml_precision:
    w_ml, w_llm = 0.3, 0.7  # LLM 强数据集
else:
    w_ml, w_llm = 0.8, 0.2  # ML 强数据集
```

或者：训练一个 meta-learner，根据任务描述（关键词）和 Round 0 ML 排名分布预测最优权重。

## 下一步（V14）

**方向**：动态权重自适应

核心问题：对 9 个数据集统一使用 w_ml=0.6 是妥协。V14 需要在线估算每个数据集的信号质量，动态切换权重。

**实现选项**：
1. **Epsilon-greedy route**：每隔 1 轮比较 ML 预测精度 vs LLM 提名精度，切换权重
2. **MAB（多臂赌博机）路由**：将 ML/LLM 各自视为一个子臂，用 Thompson Sampling 在线估算哪个信号更可靠
3. **早期信号分类**：根据 Round 1 hit 基因名称（LLM 是否提名了这些 hit？），快速判断 LLM 信号质量

预期：自适应权重后 avg > 0.260，在所有 9 个数据集上均等于或超过最优单方法。
