## 核心发现

### 1. gwps：项目历史最大单数据集突破（+0.085 vs V17）

```
gwps 各轮命中率：
        R1      R2      R3      R4      R5   hits/924
V19:   0.089   0.143   0.181   0.234   0.273   252
V21:   0.091   0.166   0.236   0.291   0.339   313    (+61 hits)
Δ:    +0.002  +0.023  +0.055  +0.057  +0.066
```

原因：gwps 是 K562 基因组全局适应度筛选，DepMap 的 pan-cancer CRISPR 数据（包含 K562）直接提供了高质量先验。ML AUC 0.652→0.751 (+0.099) 使 shortlist 中真实 hit 富集度大幅提升，LLM 从更优质的候选池中选择。

### 2. Replogle_essential：DepMap 特征反向干扰（-0.089）

```
essential 各轮命中率：
        R1      R2      R3      R4      R5   hits/63
V19:   0.095   0.254   0.381   0.460   0.571   36
V21:   0.095   0.318   0.370   0.450   0.481   30    (-6 hits)
Δ:    0.000  +0.064  -0.011  -0.010  -0.090
```

- R1 相同（初始 ML 排序，same-quality静态基线）
- R2 LLM 方差（+0.064，偶发）
- R3-R5 系统性下降（ML 更新后质量下降）→ 结构性回归

**根本原因**：Replogle_essential 筛选的是 623 个预精选基因（而非全基因组），在这 623 个基因中，DepMap 泛必需性信号不能区分"K562 特异性必需"与"一般功能性"基因。LOO AUC 从 0.658 降至 0.622（-0.036）直接导致 hit@R5 大幅下降。
