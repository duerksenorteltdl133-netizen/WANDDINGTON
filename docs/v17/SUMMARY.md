## 核心发现：temperature=0 完全确认随机性来源

### 1. Steinhart 完全确定性：0.140 == 0.140

```
Steinhart Baseline（0.6/0.4 权重）跨次结果：
  V13 (temp=0.5, run 1): 0.163  ← 高分
  V15 (temp=0.5, run 2): 0.142
  V16 (temp=0.5, run 3): 0.140
  V17 (temp=0.0, run 4): 0.140  ← 与 V16 完全相同
  
  SD(V13..V16): 0.0206  ← 随机噪声
  V16 vs V17:   0.000   ← 完全确定性
```

**V13 的 Steinhart=0.163 是 temperature=0.5 的幸运采样，不是稳定可复现的结果。** 当前策略（0.6/0.4 权重 + 跨实验记忆）在 Steinhart 上的真实稳定值是 **0.140**。

### 2. Replogle_essential 改善（+0.016）

```
V16 (temp=0.5): 0.561
V17 (temp=0.0): 0.577  (+0.016)
```

temperature=0 的贪婪解码让 LLM 稳定地优先提名概率最高的必需基因（核糖体亚基、RNA 聚合酶亚基等），不再因采样随机性偶尔错选。

### 3. Scharenberg22 从 0.463 回落至 0.456

```
V16 (temp=0.5): 0.463（偶尔采样到了更优基因）
V17 (temp=0.0): 0.456（确定性贪婪，= V13 水平）
```

这说明 V16 的 Scharenberg22=0.463 略有幸运成分。V13 与 V17 均为 0.456，是该策略的真实值。

## 剩余瓶颈与 V18 方向

当前 V17 vs 各数据集最优方法的 gap：

| 数据集 | V17 | 最优历史 | gap | 可优化方向 |
|--------|-----|---------|-----|---------|
| IFNG | 0.174 | OA 0.183 | -0.009 | 更强 ML（更多特征）|
| IL2 | 0.312 | OA 0.314 | -0.002 | 接近上限 |
| Sanchez21 | 0.078 | OA 0.087 | -0.009 | ML 调参 |
| Steinhart | 0.140 | LLM 0.152 | -0.012 | LLM 提示优化 |
| Replogle_gwps | 0.254 | V12 0.290 | **-0.036** | **最大 gap** |
| Replogle_essential | 0.577 | ~0.582 | -0.005 | 接近上限 |

**最大剩余 gap：Replogle_gwps (-0.036)**

V12（ML shortlist 约束）在 gwps 上取得 0.290，V13+ 用自由 LLM 只能达到 ~0.254-0.258。  
原因：gwps（9193 genes, 10.1% hit rate）适合先用 ML 缩窄候选池，再让 LLM 精选——这恰好是 V12 的约束方式，但 V12 对其他数据集有害。

**V18 方向**：仅对 gwps 类型数据集（中规模 + 高命中率）使用两步策略：
1. Step 1：ML 缩窄到 top-500
2. Step 2：LLM 从 top-500 中自由选（有跨实验记忆）
其余数据集维持 V17 策略（不引入新的对其他集的副作用）
