## 关键发现

### 1. Coreset 显著优于 Random（+103%）
贪心 k-center 比随机采样好一倍，说明 V7 特征空间中确实存在有意义的几何结构——覆盖多样化区域比随机探索更有效。

### 2. StaticRanker（生物学先验）显著优于 Coreset（+62%）
7/9 个数据集中，生物学先验排名 > 纯几何覆盖。这印证了 WADDINGTON_PLAN 的核心论点：**在大多数实验场景下，生物学先验知识比纯算法更有价值**。

### 3. 关键例外：瓶颈数据集 Coreset > StaticRanker

| 数据集 | 生物背景 | Coreset | StaticRanker |
|--------|---------|---------|--------------|
| Carnevale22 | 腺苷-PKA 通路 | **0.054** | 0.048 |
| Steinhart | GD2 糖脂合成 | **0.090** | 0.076 |

这正是 StaticRanker 的两个瓶颈数据集（锚点基因冷门、PPI 连接稀疏）。Coreset **不偏向 hub 基因**，反而更广泛地覆盖特征空间，在此场景中略占优势。

**解读**：当生物学先验失效时（锚点基因不是枢纽基因），无偏几何探索反而更有效。这也说明 V7 的"全局先验偏向"会在特定任务中被惩罚。

### 4. Sanchez21 中 Coreset 略低于 Random
Sanchez21 的 hit 基因（γ干扰素通路）高度集中在某些特定特征区域；Coreset 刻意分散采样，反而错过了这些聚集区域。这是 exploration-exploitation 权衡的典型案例。

## 三臂定性总结

```
冷启动优势（第1轮）：
  StaticRanker: R1_avg = 0.060  ← 先验知识立竿见影
  Coreset:      R1_avg = 0.031  ← 第1轮只能选一个种子点，效率低
  Random:       R1_avg = 0.044  ← 小数据集（Replogle_K562_essential）拉高了平均

后期斜率（R4→R5）：
  Coreset:      多数数据集依然在增长（探索未覆盖区域）
  StaticRanker: 部分数据集趋于平缓（排名靠前的区域已耗尽）
```

这意味着：**如果实验轮数足够多（>5轮），Coreset 的积累速率可能会超过静态排名器**。
