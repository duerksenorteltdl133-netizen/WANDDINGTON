## 核心发现

### 1. Scharenberg22 K562 特征有效（+0.013）

```
Scharenberg22 各轮:
         R1      R2      R3      R4      R5   hits/49
V24:    0.122   0.184   0.347   0.422   0.463   23
V25:    0.082   0.245   0.367   0.395   0.476   23
```

R1 略有波动（小池 n=1029，32 基因/轮，高方差），但 R5 改善 +0.013（23 hits 维持，但覆盖率略有变化）。K562 LOO AUC +0.033 转化为实际 hit@R5 +0.013。

Scharenberg22 是 CAR-T T 细胞耗竭筛选，与 K562（CML 细胞）共享的关键信号通路（如 MAPK、PI3K 相关基因）在 K562 中也是必需的，K562 essentiality 提供了有效正向信号。

### 2. 三层特征路由的合理性得到验证

| 层级 | 数据集 | 逻辑 | 结果 |
|------|--------|------|------|
| v1（无 DepMap）| essential, Steinhart | pan-DepMap 干扰在线学习 | 维持稳定 |
| v2（pan-cancer）| gwps, IL2, Sanchez21_down | K562 特征冗余或微损 | gwps 维持 0.339 |
| v3（pan+K562）| Scharenberg22, IFNG, Carnevale22, Sanchez21 | K562 LOO AUC 增益 | Scharenberg22 +0.013 |

### 3. 残余方差分析

- Sanchez21_down: -0.009（0.103→0.094）— 3 seeds temp=0 方差（约 ±0.010）
- essential: +0.016（0.550→0.566）— LLM 方差，非结构性
- Steinhart: +0.007 — LLM 方差

这些波动在 ±0.010-0.020 范围内，与 temp=0 跨 session 方差一致。
