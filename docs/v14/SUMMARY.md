## 失败分析

### 根本原因：EMA 过快 + 精度估计噪声过大

V14 使用 α=0.9 的 EMA 在线更新权重，理论上每轮揭示后应收敛到最优权重。但 5 轮短 benchmark 下，单轮精度估计的信噪比极低：

```
精度估计误差分析：

小数据集（Scharenberg22）：batch=32, hit_rate=49/1029≈4.8%
  期望每轮命中 ≈ 1.5 个基因
  精度标准误差 = √(0.048 × 0.952 / 32) ≈ 3.8%
  α=0.9 下，一轮精度估计主导 90% 权重 → 完全是噪声

大数据集（IFNG）：batch=128, hit_rate=802/17785≈4.5%
  期望每轮命中 ≈ 6 个基因（ML）vs 3-4 个（LLM）
  精度差 ≈ 0.10 vs 0.03，差异真实，但 σ≈1.8%
  → 信号存在，但 α=0.9 仍导致每轮权重大幅震荡
```

**α=0.9 意味着当轮精度占90%权重，前几轮积累完全失效。** 在只有5轮的评估中，这等于每轮从零开始重新学习。

### 典型失败案例

#### Replogle_essential（最大退步 -0.037）

```
Round 0: batch=32, expected hits ≈ 3-5
  若 ML 碰巧命中 4，LLM 碰巧命中 3：
    ml_prec = 4/32 = 0.125, llm_prec = 3/32 = 0.094
    → ml_ema = 0.9×0.125 + 0.1×0.6 = 0.173
    → llm_ema = 0.9×0.094 + 0.1×0.4 = 0.125
    → w_ml = 0.58, w_llm = 0.42  (小幅变化，可控)

  若 ML 碰巧命中 5，LLM 碰巧命中 1：
    ml_prec = 0.156, llm_prec = 0.031
    → w_ml = 0.71, w_llm = 0.29  (LLM 被大幅压制!)

  32 基因批次中的 1-2 个随机命中差异 → 权重剧烈变化
```

V13 固定 0.6/0.4 在两路均强的数据集上已是最优，EMA 反而引入噪声。

#### Steinhart（退步 -0.018）

V13 创造了 0.163 的历史新高（LLM 提名 BATF/IRF4 等 T 细胞基因）。V14 中，若 LLM 在 Round 0 凑巧选中了几个非 hit 的 TF（随机 API 输出），EMA 立即将 llm_ema 下调，后续轮次削减 LLM 权重，错过 LLM 专业知识最强的轮次。

### 表面上改善的数据集

| 数据集 | V14 vs V13 | 实际原因 |
|--------|-----------|---------|
| Sanchez21 | +0.004 | LLM API 随机性，不是 EMA 效果 |
| Sanchez21_down | +0.002 | 同上 |
| Replogle_gwps | +0.001 | 统计噪声 |

改善幅度均在单轮命中数的随机误差范围内（±1 个基因 = ±0.001~0.003 precision）。

## 设计缺陷总结

| 问题 | 影响 |
|------|------|
| α=0.9 太激进 | 一轮精度估计支配全部权重 |
| 5轮 < EMA 收敛需要的最少轮次 | 权重在噪声中震荡，无法收敛 |
| 32-128 基因批次的精度估计 SE 过大 | σ≈2-4%，信噪比不足 |
| LLM API 随机性（temperature=0.5）| 两次实验的 LLM picks 不同，无法公平对比 EMA 效果 |

**结论**：在 ≤10 轮的短 benchmark 中，实时精度 EMA 是错误的适应机制。

## 正确方向：V15 静态预分类路由

既然在线学习失败，改用**离线路由**：根据数据集特征（实验前可知）预测最优权重。

### 历史数据支持的规律

```
小基因池（< 2000 genes）：
  Scharenberg22 (1029 genes): LLM wins (0.469)
  Replogle_essential (623 genes): LLM wins (0.550)
  → w_llm = 0.7, w_ml = 0.3

高命中率（> 8%）：
  Replogle_essential: hit_rate=63/623=10.1% → LLM wins
  Replogle_gwps: hit_rate=924/9193=10.1% → borderline
  → w_llm = 0.6, w_ml = 0.4

大基因池 + 低命中率（> 15000 genes, < 6%）：
  IFNG (17785 genes, 4.5%): OA wins
  IL2 (18273 genes, 2.6%): OA wins
  Sanchez21 (17807 genes, 4.8%): OA wins
  → w_llm = 0.2, w_ml = 0.8
```

### V15 路由规则（基于 gene_pool_size + expected_hit_rate）

```python
def route_weights(n_genes, n_hits):
    hit_rate = n_hits / n_genes
    if n_genes < 2000:           # 小数据集 → LLM 擅长
        return 0.3, 0.7
    elif n_genes > 15000 and hit_rate < 0.06:  # 大基因池, 稀疏 hit → ML 擅长
        return 0.8, 0.2
    else:                        # 中等 → V13 均衡先验
        return 0.6, 0.4
```

**预期效果**：
- IFNG: w_ml=0.8 → 接近纯 OA (0.183)
- IL2: w_ml=0.8 → 接近纯 OA (0.314)
- Scharenberg22: w_llm=0.7 → 接近纯 LLM (0.469)
- Replogle_essential: w_llm=0.7 → ≥ V13 (0.582)
- Steinhart: 大基因池但 hit_rate=0.8% → w_ml=0.8？或单独处理

Steinhart 是例外（18144 genes，但 LLM 最强）。需要第三个规则：当 task description 包含特定癌症/肿瘤关键词时偏向 LLM。

**预期 avg ≥ 0.250**（当前最高 V13=0.232）
